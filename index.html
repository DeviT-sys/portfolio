FEATURED PROJECT

Automated Retail Sales Analytics Using Azure and Power BI

An end-to-end, fully automated analytics solution: from raw point-of-sale files to refreshed Power BI dashboards, with no manual steps in between.

The problem

Retail sales data arrives daily as flat files from stores and an e-commerce platform. Reporting was manual: copy, clean, merge in Excel, then email. The result was stale numbers, inconsistent definitions and hours of analyst time per cycle.

The solution

An automated pipeline on Azure that ingests, cleans, models and publishes sales data on a schedule, feeding a governed Power BI semantic model and a set of decision-ready dashboards.

Azure Data FactoryADLS Gen2Azure Databricks / PySparkAzure SQL DatabasePower BIDAXAzure DevOpsKey Vault

End-to-end architecture

SourcesStore POS CSVs, e-commerce orders, product & store master data
→
IngestAzure Data Factory, scheduled and event triggers
→
BronzeADLS Gen2 raw landing zone
→
SilverDatabricks: clean, dedupe, validate
→
GoldAzure SQL star schema
→
ServePower BI dataset, scheduled refresh

1 · Ingestion

  • ADF pipelines copy daily files into the raw container, partitioned by date.
  • Parameterized datasets so new stores or sources need configuration, not new code.
  • Secrets held in Key Vault; failures trigger alerts.

2 · Transformation

  • PySpark notebooks standardize schemas, fix data types, remove duplicates and handle nulls.
  • Rule-based validation: negative quantities, missing keys, orphan product IDs.
  • Rejected rows are quarantined with a reason code for review.

3 · Modeling

  • Star schema: FactSales with DimDate, DimProduct, DimStore, DimCustomer.
  • Incremental loads using a watermark column and upsert logic.
  • Indexed for report query performance.

4 · Automation & Governance

  • ADF trigger runs the full chain nightly, then refreshes the Power BI dataset.
  • Pipeline code under Git with Azure DevOps CI/CD across dev and prod.
  • Row-level security by region in Power BI.

Sample DAX measures

Total Revenue = SUM ( FactSales[NetAmount] )

Gross Margin % =
DIVIDE ( [Total Revenue] - SUM ( FactSales[Cost] ), [Total Revenue] )

Revenue YoY % =
VAR Prev = CALCULATE ( [Total Revenue], SAMEPERIODLASTYEAR ( DimDate[Date] ) )
RETURN DIVIDE ( [Total Revenue] - Prev, Prev )

PROJECT 4 · PYTHON · PUBLIC HEALTHCARE DATASETS

Healthcare Data Analysis in Python: Heart Disease, Diabetes & Breast Cancer

Data-driven insights from real-world healthcare data, produced through exploratory and statistical analysis with pandas, seaborn and matplotlib on three well-known public datasets.

Objective

For each dataset, understand its structure and quality, find which patient measurements separate people with and without the condition, and back the patterns with statistical tests so the conclusions rest on evidence.

PythonJupyterpandasNumPyseabornmatplotlibSciPyEDAHypothesis Testing

UCI Heart Disease

Cleveland data: 303 patients and 14 attributes, including age, sex, chest pain type, resting blood pressure, cholesterol and maximum heart rate.

  • Compare distributions for patients with and without heart disease.
  • Correlation analysis across clinical measures.
  • t-tests for numeric variables, chi-square for categorical ones.

Pima Indians Diabetes

NIDDK data: 768 records with 8 predictors (glucose, BMI, blood pressure, insulin, age and more) and a diabetes outcome.

  • Zeros in glucose, blood pressure, BMI and insulin are not physiologically valid, so they were treated as missing values.
  • Imputed and compared groups by outcome.
  • Feature relationships with the outcome.

Breast Cancer Wisconsin (Diagnostic)

569 samples with 30 numeric features computed from cell nucleus images, labeled benign or malignant.

  • Feature distributions by diagnosis.
  • Heatmap to find highly correlated features.
  • Tests on which measurements differ most between classes.

Sample Python code

import numpy as np
import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt
from scipy import stats

df = pd.read_csv("diabetes.csv")

# zeros are invalid for these columns
cols = ["Glucose", "BloodPressure", "BMI", "Insulin"]
df[cols] = df[cols].replace(0, np.nan)
df[cols] = df[cols].fillna(df[cols].median())

sns.boxplot(data=df, x="Outcome", y="Glucose")
plt.show()

a = df.loc[df.Outcome == 1, "Glucose"]
b = df.loc[df.Outcome == 0, "Glucose"]
print(stats.ttest_ind(a, b, equal_var=False))
